# DKCRPG Production Art

Selected technical-art and illustration assets from Hunter Hatfield's independent Donkey Kong Country-inspired RPG project.

The featured pre-render pipeline recreates the broad workflow used by SNES-era games such as Donkey Kong Country and Super Mario RPG: model and rig a character in 3D, pose/render animation frames, then process the renders into low-resolution 2D game assets. The project also includes hand-drawn Clip Studio character portraits and other custom production artwork.
